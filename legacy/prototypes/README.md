# Legacy Prototypes

These artifacts informed earlier RainTech GRC discussions but are not part of
the approved fresh-start application.

## `old-grc-platform-perplexity-index.html`

The older all-in-one GRC shell created before the fresh-start decision. It
expects backend routes that may not be available and should be treated as visual
reference only.

## `cui-readiness-quote-customer.html`

The standalone customer-facing CUI readiness and quote tool. Its questions,
pricing concepts, and customer wording may inform the new project intake and
CMMC estimate workflow, but its code will not be promoted directly.
