A key activity carrying an `Implementation Specification (Required | Addressable)` marker routes its questions to the specification it names. An unmarked activity addresses the standard as a whole, so its questions stay on the parent as introductory guidance; the parent's status is derived from its children and it carries no editable determination.

Prompts carry no status, produce no findings, and never appear in a report as assessable items.
