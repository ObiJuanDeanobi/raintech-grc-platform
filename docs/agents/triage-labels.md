# Triage Labels

Use the default Matt Pocock triage vocabulary:

| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs more information | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

These labels are for issue workflow state. Keep product area labels, such as `v1-profile`, `evidence`, `reports`, and `documents`, separate from triage state.

Use the product label `tech-debt` only for debt that was consciously accepted
with a concrete reason and revisit point.
