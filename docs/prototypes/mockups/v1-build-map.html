Dependencies and open decisions

Only you can do these

  • Windows verification — launcher, packaging, offline operation, backup and restore. No cloud session can test any of it.
  • Practitioner review of both catalogs — HIPAA is open on #21; CMMC follows #30. Yours is the cheap one, since you know the framework cold.
  • RainTech templates — policy, procedure, report and SSP. Unstarted, and Slice 6 cannot finish without them.
  • CMMC pricing rules — the baselines exist in the specification but need your confirmation before the estimate is built.

What could still bite

  • Packaging discovered late. If the stack will not package for Windows ARM64, the current plan finds out in the final slice. #32 exists to answer it now.
  • Privacy and Breach have no independent control. The Security Rule has Appendix A, which caught one missing standard. The other two rules have nothing — and practitioner review then found a second standard missing.
  • Prompt extraction is unreliable. The OCR Audit Protocol is a filterable web page, not a structured download. Two of four sample entries could not be retrieved.
  • Catalog staleness is silent. Nothing detects a change to 45 CFR Part 164. The mitigation is entirely procedural today.

Deferred decisions

Parked deliberately, each with a trigger, so they resurface on their own rather than when somebody happens to remember.

Trigger · first engagement complete Narrow the V1 boundary — split the required and optional halves of Slices 2, 5 and 7. The single biggest lever on how long V1 takes. Deferred rather than dropped because running one engagement is what tells us which half is genuinely required. It blocks nothing before Slice 2.
Trigger · final Security Rule published Re-ingest the HIPAA catalog. Currently manual, tracked on #25. The January 2025 NPRM would remove the addressable category. Currently targeted July 2027. That produces a new catalog version, not a schema migration.
Decided · out of scope Shared responsibility modelling — the MSP responsibility matrix. Not ingested and not modelled. Recorded so it is not reopened by whoever next opens the workbook. If it returns it is a specification change, not an extraction task.
