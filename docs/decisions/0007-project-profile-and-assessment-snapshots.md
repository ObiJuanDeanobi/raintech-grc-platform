# ADR 0007 - Project Profile and Assessment Snapshots

## Status

Accepted

## Decision

The profile belongs to the project and is progressively refined throughout
delivery. Issued assessments and reports capture immutable profile snapshots.
Assessments are snapshots; remediation is continuous at project level.

## Context

Onboarding cannot fully describe the client environment. Gap analysis and
evidence work will correct assumptions and establish current and target states.
Historical outputs must remain reproducible while the live profile and
remediation continue changing.

## Consequences

- A client may have independent profiles for CMMC and HIPAA projects.
- The live profile records current state, target state, deltas, and unknowns.
- Reassessment copies prior answers as Needs Revalidation.
- Open findings, risks, and POA&M work carry forward by reference.
- Issued assessments are not silently changed by later profile updates.
